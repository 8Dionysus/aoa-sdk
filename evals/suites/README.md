# Suites

Deterministic SDK suites live here when they preserve local compatibility,
handoff, or control-plane fixtures. Each executable suite must pair a
`*.suite.md` design note with a validator-admitted `*.suite.json` execution
contract.

Draft comparative designs may remain note-only while their runner and
acceptance protocol are still under owner review. They are not executable
proof and cannot issue a verdict from draft status.

Central verdict, scoring, regression, and proof doctrine routes stay in
`aoa-evals`.
