# Agon Gate Routing Bridge

## Role

This part carries the routing-owned, pre-protocol Agon gate function into the
SDK control plane after the G5 owner switch.

## Input

- packaged source config:
  `src/aoa_sdk/control_plane/routing/data/agon_gate_routing.config.json`;
- center-owned lawful move vocabulary when it is locally available;
- the owner-dispatch seam example in this part.

## Output

- importable builder and validator:
  `aoa_sdk.control_plane.routing.agon`;
- wheel-packaged compatibility registry:
  `src/aoa_sdk/control_plane/routing/data/agon_gate_routing_registry.min.json`;
- SDK-owned owner-dispatch seam schema and a part-local example;
- a pinned succession receipt for the predecessor-to-SDK semantic delta.

## Owner

`aoa-sdk` owns route candidates, deterministic construction, schema validation,
and next-hop orientation. `Agents-of-Abyss` retains Agon law and sovereignty.
The named sibling repositories retain actor, proof, memory, playbook, stats,
KAG, and Tree of Sophia meaning.
